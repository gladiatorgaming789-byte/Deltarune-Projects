Item Giver + Secret Boss Challenge v0.1.0

This is the compatibility build for:
- Item Giver Mode v0.1.4
- Secret Boss Challenge v0.4.0

IMPORTANT
Install this merged package INSTEAD OF installing Item Giver Mode and Secret Boss Challenge as two separate mods. Disable/remove the separate copies first so their patches are not applied a second time.

ITEM GIVER
- Press F7 outside battle to open or close Item Giver.
- Categories: Items, Weapons, Armor, Key Items, Light Items.
- Z / Enter gives the selected entry.
- Arrow keys navigate.
- Page Up / Page Down jump ten entries.
- R refreshes item definitions.
- X / Escape / F7 closes.

SECRET BOSS CHALLENGE
- Contains the complete Secret Boss Challenge v0.4.0 behavior for Chapters 1, 2, and 5.
- Chapter 5 Boss Challenge rewards include Pink Scarf and Pink Coins.
- Pink's Staff requires Boss Challenge plus Meaner Bombs.
- Pink Scarf grants Ralsei Shield and its graze passive.

WHY THIS BUILD EXISTS
Deltamod multiple-mod merging uses G3MTool. CSX mods are materialized independently from the clean game before resource merging. This package applies both source patches together inside one chapter patch so the final result matches the known-good sequential build.

Target: DELTARUNE Windows full release, launcher version v23.
