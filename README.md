# Deltarune Projects

Development repository for DELTARUNE mods maintained by GladiatorGaming.

All mods in this repository are designed to be packaged for Deltamod. Each mod keeps its distributable files, source patch scripts, and test notes in its own directory under `mods/`.

## Mods

- [Secret Boss Challenge](mods/secret-boss-challenge/README.md) — optional harder versions of the Chapter 1 and Chapter 2 secret bosses with both route rewards.
