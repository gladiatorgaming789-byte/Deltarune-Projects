# Deltarune Projects

Development repository for DELTARUNE mods maintained by GladiatorGaming.

All mods in this repository are designed and packaged for Deltamod.

## Repository workflow

- All mod-development work is committed directly to the `mod-development` branch.
- Do not create temporary, feature, agent, or release branches for individual mods.
- Every standalone mod lives in its own directory under `mods/<mod-name>/`.
- Each mod directory keeps its source patch scripts, Deltamod release archives, documentation, and test reports together.
- Merged compatibility builds must use their own clearly named directory rather than replacing either source mod.
- Do not commit original DELTARUNE executables, `data.win` files, music, or other copyrighted game assets.
