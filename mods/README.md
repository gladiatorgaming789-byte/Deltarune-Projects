# Mods

This folder contains completed **original DELTARUNE mods** created for this project.

## Published projects

_No completed standalone mod has been archived here yet._

Projects remain on the `mod-development` branch until their release package, documentation, and testing are complete.

## Expected project layout

Each mod should use its own clearly named folder:

```text
mods/
└── mod-name/
    ├── README.md
    ├── Mod_Name_v1.0.0_Deltamod.zip
    ├── source-or-patches/
    └── tests/
```

The exact supporting folders may vary, but every project README should identify the latest release and explain what each included file is for.

## Release checklist

Before a mod is listed here, verify that it:

- Installs through Deltamod.
- Targets the documented DELTARUNE version and chapters.
- Does not include copyrighted game files.
- Preserves normal game behavior when optional features are disabled.
- Documents installation, features, configuration, compatibility, conflicts, known issues, credits, and license information.
- Includes repeatable validation results or a test report.

## Naming

Use lowercase folder names with words separated by hyphens when practical, such as `secret-boss-challenge`. Release archives should include the mod name, semantic version, and `Deltamod` in the filename.
