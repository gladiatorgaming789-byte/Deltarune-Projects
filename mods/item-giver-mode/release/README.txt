Item Giver Mode v0.1.4

Install this ZIP directly through Deltamod. Keep the archive intact.

WHAT CHANGED IN v0.1.4
- The Item Giver interface now renders in Draw GUI End so DELTARUNE menus cannot draw over it afterward.
- Added a full-screen dim layer and an opaque centered panel.
- Layout now uses the current GUI width and height instead of assuming one fixed window size.
- Item names replace # line-break markers with spaces and long names are shortened in list rows.
- Preview and status text use wrapped drawing inside the panel.
- F7 remains the menu hotkey.

CONTROLS
- F7: Open or close
- Left / Right: Change category
- Up / Down: Select an item
- Page Up / Page Down: Jump by 10 entries
- Home / End: First or last entry
- Z or Enter: Give the selected item
- R: Refresh the item tables
- X or Escape: Close

CATEGORIES
- Items
- Weapons
- Armor
- Key Items
- Light Items

IMPORTANT SAVE WARNING
This is a debug utility. Some key items and unused/developer items are tied to plot flags or scripted events. Giving an item does not automatically set every story flag normally associated with earning it. Use a backup save before experimenting with progression-sensitive items.

Target: DELTARUNE Windows full release, launcher version v23.
